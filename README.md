# 견적정리

쇼핑몰 주문 내역을 검수하고 학교 물품구입 견적서로 정리하는 웹앱입니다.
기계가 값을 옮기되, 취소·반품 여부와 불확실한 품명은 사람이 마지막으로 판단하도록 설계했습니다.

## 주요 기능

- 최대 20개 상품 링크를 한 줄에 하나씩 붙여넣어 편집 가능한 견적 초안을 생성
- JSON-LD → 가격 메타 → itemprop → 본문 추정 순서로 가격을 찾고 출처·신뢰도·옵션 가격대 표시
- 자동 조회가 차단되어도 링크와 상품번호를 보존하고, 설치 없는 상품 탭 선택 캡처로 상품명·판매가 초안을 생성
- 로그인 주문 화면 북마크 방식은 여러 상품을 한꺼번에 가져오는 고급 기능으로 유지
- PDF, XLSX 엑셀 견적서, PNG·JPG 장바구니 캡처를 브라우저에서 분석
- 화면 텍스트 붙여넣기, 브라우저 도우미, JSON·CSV, 직접 입력은 예외 상황용으로 유지
- V-P01·V-P02로 쇼핑몰 화면 구조 변경이나 빈 추출을 즉시 중단
- 수량 또는 가격 기준을 확인할 수 없으면 V04·V11로 표시하고 엑셀 생성을 잠금
- 순번, 내용, 규격, 단위, 수량, 예상단가, 예상금액을 항목별로 검수
- 구매 전 링크 경로는 예산 한도 대비 잔액·초과(V15), 구매 후 주문 경로는 결제 총액 대비 차액을 실시간 계산
- 검수 결과를 `order.reviewed.json`으로 저장
- 매 장 고정 18개 품목행과 금액 수식을 유지한 다매 `.xlsx` 견적서 생성
- 문서·캡처·주문 데이터는 브라우저 안에서 처리하며, 공개 상품 조회에는 상품번호만 사용

## 가장 빠른 사용 방법

1. 상품 링크를 한 줄에 하나씩 첫 화면에 붙여넣습니다.
2. **상품 초안 만들기**를 누릅니다.
3. 가격 출처·신뢰도와 자동으로 채워진 상품명·공개 판매가를 확인합니다.
4. 실제 수량·선택 옵션 가격과 필요하면 예산 한도를 입력합니다.
5. **확인한 품목을 검수표에 추가**하고 예상 합계를 확인한 뒤 엑셀 견적서를 만듭니다.

공개 링크라도 쇼핑몰의 외부 읽기 정책에 따라 상품명이나 가격 확인이 차단될 수 있습니다. 이 경우 오류 화면에서 멈추지 않고 상품 링크와 상품번호를 보존한 초안을 표시합니다. **원본 화면 열기**로 상품을 띄운 뒤 **상품 화면 선택**을 누르고 브라우저 창에서 해당 상품 탭을 선택하면, 화면 한 장을 자동 캡처하고 공유를 즉시 종료한 뒤 OCR로 상품명과 판매가를 채웁니다. 인식 결과는 예상값이므로 선택 옵션과 최종 판매가를 원본과 한 번 대조합니다.

G마켓 상품 링크는 `goodscode`만 남긴 안정적인 주소로 정리합니다. 공개 JSON-LD와 상품 메타데이터가 있으면 상품명과 판매가를 먼저 채우며, 본문에서 추정한 가격·옵션 가격대·외화는 낮은 신뢰도와 확인 메시지를 표시합니다. 링크에 없는 수량·옵션·쿠폰가·배송비는 자동 확정하지 않습니다. 구매 전 링크 목록에는 결제 총액이 없어도 오류로 처리하지 않고 예산 한도(V15)로 초과 여부를 확인합니다. 북마크 방식은 로그인 주문의 여러 상품을 파일 없이 한꺼번에 가져와야 할 때만 고급 기능에서 사용합니다.

링크 방식이 잘 되지 않으면 **문서·사진**에서 쇼핑몰이 내려준 XLSX 또는 PDF를 올립니다. 그다음 권장 수단은 글자를 크게 확대한 장바구니 캡처입니다. 화면 텍스트 붙여넣기는 상품 카드 경계와 가격 의미가 사라질 수 있어 마지막 보조 수단으로만 사용합니다. 주문 텍스트·문서·캡처는 서버에 저장하지 않고 브라우저 안에서 처리합니다.

아이스크림몰·쿠팡·G마켓·YES24 주문 화면을 붙여넣으면 각 쇼핑몰의 상품 카드와 표 구조를 먼저 구분합니다. 정가 또는 취소선 가격 뒤에 할인가가 있으면 마지막 최종 상품금액을 적용하고, 쿠폰·할인율·포인트·캐시적립·판매자·도착 안내는 상품명 후보에서 제외합니다. `상품 금액 ÷ 수량` 또는 명시된 `1개당 가격`으로 예상단가를 계산합니다. `무료배송`은 품목으로 만들지 않으며 실제 금액이 함께 표시된 배송비는 수량 1, 단위 `건`, 내용 `배송비`인 별도 품목으로 추가합니다.

링크가 없는 합배송 스크랩은 `단일상품 / 수량` 또는 `규격 / 수량`, 표시 금액의 순서로 상품 경계를 찾습니다. 브랜드와 상품명은 하나의 내용으로 합치고, 판매자명과 `50,000원 이상 무료배송` 같은 정책 문구는 품목에서 제외합니다. YES24 표는 `할인금액`을 예상단가로, `합계`를 예상금액으로 사용하며 YES포인트는 가격에서 제외합니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

최종 빌드와 검증은 다음 명령으로 실행합니다.

```bash
npm test
```

## 입력 형식

```json
{
  "mall": "coupang",
  "orderNo": "20260821-0001",
  "paidTotal": 77800,
  "items": [
    {
      "내용": "비커 250mL",
      "규격": "붕규산 3.3유리",
      "단위": "개",
      "수량": 20,
      "단가": 2400,
      "금액": 48000,
      "_rawName": "[쿠팡] 무료배송 비커 250mL 20개입",
      "excluded": false
    }
  ]
}
```

## 회계 안전 원칙

- 견적서는 최대 18개의 고정 품목행만 사용합니다.
- 품목이 18개를 넘으면 여러 시트로 나누고 각 시트에 전체 합계와 매수를 표시합니다.
- 각 시트는 `순번 · 내용 · 규격 · 단위 · 수량 · 예상단가 · 예상금액` 순서를 유지합니다.
- 예상금액 셀은 `수량 × 예상단가` 수식으로 생성합니다.
- 결제 총액을 찾지 못하거나 품목 합계와 다르면 차액을 표시하고 견적서 생성을 잠급니다.
- 한 장짜리 견적서에는 불필요한 `1매 중 1매` 문구를 표시하지 않습니다.
- 확실하지 않은 값은 자동 추정하지 않고 규칙 ID와 함께 확인 대상으로 남깁니다.
- 취소·반품 항목은 삭제하지 않고 `excluded: true`로 보존합니다.

이 앱이 만드는 견적서는 학교 내부 품의·정리용 자료입니다. 공급자가 발행한 원본 증빙을 대체하지 않으므로 거래명세서, 세금계산서, 카드전표 등은 별도로 보관하세요.
