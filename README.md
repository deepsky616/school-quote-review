# 에듀파인 품의내역 생성기

쇼핑몰 주문 내역을 검수하고 학교 물품구입 견적서로 정리하는 웹앱입니다.
기계가 값을 옮기되, 취소·반품 여부와 불확실한 품명은 사람이 마지막으로 판단하도록 설계했습니다.

## 주요 기능

- 쇼핑몰 주문 화면 전체를 복사해 붙여넣으면 상품명·옵션·수량·최종 할인가를 자동 정리
- 쿠폰·할인율·적립금·판매자·배송 상태를 상품명에서 제외하고 유료 배송비는 별도 품목으로 분리
- 스텝 1을 `주문 화면 복사·붙이기`, `PDF 문서`, `종이 견적서·영수증` 탭으로 분리
- 브라우저 인쇄에서 저장한 YES24·교보문고·G마켓·아이스크림몰·11번가·만안문구센터·티처몰 주문내역 PDF를 쇼핑몰별 좌표 규칙으로 분석
- 선택 설치하는 브라우저 도우미는 `dataLayer`·`__NEXT_DATA__`·JSON-LD 구조화 데이터(L2)를 먼저 읽고, 없을 때만 화면 행(L3)을 분석
- 각 품목에 추출 계층(L2~L6)과 신뢰 수준을 표시해 먼저 확인할 행을 구분
- V-P01·V-P02로 쇼핑몰 화면 구조 변경이나 빈 추출을 즉시 중단
- 수량 또는 가격 기준을 확인할 수 없으면 V04·V11로 표시하고 엑셀 생성을 잠금
- 순번, 내용, 규격, 단위, 수량, 예상단가, 예상금액을 항목별로 검수
- PDF에서 누락된 품목은 공통 검수표에서 직접 추가하고, 직접 추가한 행은 바로 삭제
- 구매 전 주문은 예산 한도 대비 잔액·초과(V15), 구매 후 주문은 결제 총액 대비 차액을 실시간 계산
- 첨부된 `품목내역(통합)` 구조와 같은 `내용 · 규격 · 단위 · 수량 · 예상단가` 5열 `.xlsx` 생성
- 붙여넣은 주문 내용과 문서·캡처는 브라우저 안에서 처리

## 가장 빠른 사용 방법

1. 쇼핑몰의 주문결제 페이지에서 전체 내용을 선택해 복사합니다(`Ctrl+A` → `Ctrl+C`). 쿠팡만 장바구니 페이지에서 복사합니다.
2. 웹앱 첫 화면의 입력칸에 붙여넣습니다(`Ctrl+V`).
3. **품목 자동 작성**을 누릅니다.
4. 자동으로 분리된 상품명·수량·예상단가·배송비와 노란 확인 표시를 검토합니다.
5. 예상 합계를 확인한 뒤 엑셀 견적서를 만듭니다.

첫 화면의 **주문 화면 열기**에는 G마켓·11번가·쿠팡·YES24·교보문고·아이스크림몰·티처몰·만안문구센터 순서로 바로가기가 있습니다. 일반 쇼핑몰은 `주문결제 페이지`, 쿠팡은 `장바구니 페이지`, 만안문구센터만 `주문결제 페이지 PDF`로 안내합니다. 이 링크는 자동 수집용이 아니라 해당 쇼핑몰 화면을 빠르게 여는 용도입니다. 일반 화면은 전체 선택·복사한 뒤 웹앱에 붙여넣고, 만안문구센터는 주문결제 페이지를 PDF로 저장해 올립니다.

텍스트 복사가 어렵거나 표 구조가 사라지는 쇼핑몰은 스텝 1의 **PDF 문서** 탭을 선택합니다. 주문결제 페이지(쿠팡은 장바구니 페이지)에서 `Ctrl+P`를 누르고 `PDF로 저장` 또는 `Microsoft Print to PDF`를 선택한 뒤, 전체 페이지를 저장해 웹앱에 올립니다. 종이 자료는 오른쪽의 **종이 견적서·영수증** 탭에서 휴대폰 문서 스캔 또는 스캔 기능이 있는 프린터·복합기 방법을 선택합니다. 복합기는 원고대·자동급지대(ADF)를 사용하고 PDF·300dpi·문자 인식(OCR)을 설정해 여러 장을 한 파일로 저장합니다. 만든 PDF는 탭을 이동하지 않고 같은 화면의 업로드 영역에서 바로 품목으로 정리할 수 있습니다. 사진·이미지는 직접 받지 않으며, 주문 텍스트와 PDF는 서버에 저장하지 않고 브라우저 안에서 처리합니다.

종이 견적서·영수증 PDF는 `번호 → 품목 → 규격 → 수량 → 단위 → 단가 → 공급가액(금액)` 열의 위치를 자동으로 찾습니다. `순번·일련번호`, `품명·상품명·물품명`, `판매단가·공급단가`, `공급액·판매금액`처럼 비슷한 열 이름과 `공급 / 가액`처럼 두 줄로 나뉜 머리글도 인식합니다. 규격·단위 열이 있으면 그대로 옮기고, 순번이 없는 표는 표 머리글 아래의 수량 위치를 기준으로 행을 구분합니다. 여러 줄 품목명과 머리글이 반복되지 않은 다음 쪽도 앞쪽 열 위치에 맞춰 이어서 읽습니다. 같은 표를 **주문 화면 복사·붙여넣기** 탭에 붙이는 경우에도 행 앞의 순번은 상품명에서 제외하고, 줄바꿈된 상품명은 다음 수량·단가·공급가액과 연결합니다.

만안문구센터 PDF는 표의 열 위치를 기준으로 `제품명 → 내용`, `판매단가 → 예상단가`, `수량 → 수량·단위`, `합계 → 예상금액`으로 옮깁니다. 색상 옵션은 규격으로 분리하고, 구입총액은 품목 합계와 대조합니다.

YES24·교보문고·G마켓·아이스크림몰·11번가·티처몰 PDF는 실제 주문 화면 예시의 열·행 좌표를 기준으로 전용 규칙을 적용합니다. YES24는 도서 제목·수량·할인금액·합계 열을 읽습니다. 교보문고는 반복된 상품명을 한 번만 사용하고, 상품명 뒤 또는 다음 줄의 `1개`를 수량으로 분리하며, 수량 옆의 첫 원 금액을 예상금액으로 사용하고 그다음 원 금액은 할인 전 원가로 제외합니다. G마켓은 상품 카드의 마지막 할인가와 가장 오른쪽 배송비, 11번가는 상품명·옵션·수량·할인모음가·선결제 배송비 열, 아이스크림몰은 상품명·단일상품 수량·표시 합계를 각각 읽습니다. 티처몰은 `상품번호 다음 글자 → 내용`, `옵션 → 규격`, `옵션 뒤 첫 숫자 → 수량`, `상품 가격 구간의 마지막 원 금액 → 예상금액` 순서로 읽고 예상금액을 수량으로 나눠 예상단가를 계산합니다. `택배` 바로 다음 결과에 원 금액이 있을 때만 규격이 빈 배송비 품목으로 추가하며 무료 표시는 제외합니다.

자동 품목 구분은 웹앱 첫 화면에 표시된 지원 쇼핑몰을 기준으로 최적화되어 있습니다. 그 밖의 쇼핑몰 PDF는 PDF 내부의 글자 좌표와 저장 순서를 한 줄씩 다시 조합한 뒤 일반 주문 화면 규칙을 적용하므로, 화면의 표 순서와 PDF 내부 글자 순서가 다르면 상품명·수량·가격 연결이 어긋날 수 있습니다. 이 경우 노란 표시를 확인하고 검수표의 **품목 추가**로 보완합니다. 새로운 쇼핑몰을 정확히 지원하려면 해당 쇼핑몰의 실제 예시 PDF에 맞춘 전용 규칙이 필요합니다.

아이스크림몰·쿠팡·G마켓·YES24·11번가 주문 화면을 붙여넣으면 각 쇼핑몰의 상품 카드와 표 구조를 먼저 구분합니다. 정가 또는 취소선 가격 뒤에 할인가가 있으면 마지막 최종 상품금액을 적용하고, 쿠폰·할인율·포인트·캐시적립·판매자·도착 안내는 상품명 후보에서 제외합니다. `상품 금액 ÷ 수량` 또는 명시된 `1개당 가격`으로 예상단가를 계산합니다. `무료배송`은 품목으로 만들지 않으며 실제 금액이 함께 표시된 배송비는 수량 1, 단위 `건`, 내용 `배송비`인 별도 품목으로 추가합니다.

링크가 없는 합배송 스크랩은 `단일상품 / 수량` 또는 `규격 / 수량`, 표시 금액의 순서로 상품 경계를 찾습니다. 브랜드와 상품명은 하나의 내용으로 합치고, 판매자명과 `50,000원 이상 무료배송` 같은 정책 문구는 품목에서 제외합니다. YES24 표는 `할인금액`을 예상단가로, `합계`를 예상금액으로 사용하며 YES포인트는 가격에서 제외합니다.

11번가는 `할인모음가`를 예상단가로 사용하고 `판매가`는 제외합니다. `옵션`은 규격으로 옮기며, `선결제` 배송비는 규격이 빈 별도 배송비 품목으로 추가합니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

최종 빌드와 검증은 다음 명령으로 실행합니다.

```bash
npm test
```

GitHub Pages용 정적 파일은 다음 명령으로 만듭니다. `main` 브랜치에 반영되면 GitHub Actions가 자동으로 배포합니다.

```bash
npm run build:pages
```

## 엑셀 양식과 안전 원칙

- 화면 검수표는 `순번 · 내용 · 규격 · 단위 · 수량 · 예상단가 · 예상금액`을 보여 줍니다. 순번 옆 체크가 켜진 품목만 엑셀에 포함되며, 체크가 꺼진 품목은 제외됩니다. 순번 머리글의 체크박스로 모든 품목을 한 번에 선택하거나 해제할 수 있고, 일부만 선택하면 부분 선택 상태로 표시됩니다.
- 다운로드 파일은 붙임 양식과 동일하게 `품목내역` 한 시트와 `내용 · 규격 · 단위 · 수량 · 예상단가` 5개 열만 사용합니다.
- 선택된 품목은 화면의 위쪽부터 1번으로 다시 정리되어 빈 행 없이 연속된 엑셀 행으로 생성됩니다. 체크가 꺼진 품목의 확인 경고는 엑셀 생성을 막지 않습니다.
- 예상금액은 화면에서 `수량 × 예상단가`로 확인하며 가져오기용 엑셀에는 추가하지 않습니다.
- 결제 총액을 찾지 못하거나 품목 합계와 다르면 차액을 표시하고 견적서 생성을 잠급니다.
- 확실하지 않은 값은 자동 추정하지 않고 규칙 ID와 함께 확인 대상으로 남깁니다.
- 취소·반품 항목은 삭제하지 않고 `excluded: true`로 보존합니다.

이 앱이 만드는 견적서는 학교 내부 품의·정리용 자료입니다. 공급자가 발행한 원본 증빙을 대체하지 않으므로 거래명세서, 세금계산서, 카드전표 등은 별도로 보관하세요.
