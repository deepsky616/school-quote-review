# 견적정리

쇼핑몰 주문 내역을 검수하고 학교 물품구입 견적서로 정리하는 웹앱입니다.
기계가 값을 옮기되, 취소·반품 여부와 불확실한 품명은 사람이 마지막으로 판단하도록 설계했습니다.

## 주요 기능

- 장바구니 공유 링크와 공개 주문 링크를 첫 화면에서 바로 분석
- 로그인 주문 화면은 설치 없이 쓰는 북마크 버튼으로 구조화된 상품 카드와 원본 링크를 전달
- PDF, XLSX 엑셀 견적서, PNG·JPG 장바구니 캡처를 브라우저에서 분석
- 화면 텍스트 붙여넣기, 브라우저 도우미, JSON·CSV, 직접 입력은 예외 상황용으로 유지
- V-P01·V-P02로 쇼핑몰 화면 구조 변경이나 빈 추출을 즉시 중단
- 수량 또는 가격 기준을 확인할 수 없으면 V04·V11로 표시하고 엑셀 생성을 잠금
- 순번, 내용, 규격, 단위, 수량, 예상단가, 예상금액을 항목별로 검수
- 결제 총액 대비 포함 품목 합계와 차액 실시간 계산
- 검수 결과를 `order.reviewed.json`으로 저장
- 매 장 고정 18개 품목행과 금액 수식을 유지한 다매 `.xlsx` 견적서 생성
- 모든 주문 데이터는 브라우저 안에서만 처리하며 서버로 전송하지 않음

## 가장 빠른 사용 방법

1. 장바구니 공유 링크 또는 주문 상세 링크를 첫 화면에 붙여넣습니다.
2. **링크에서 가져오기**를 누릅니다.
3. 로그인 때문에 읽을 수 없으면 초록색 **견적정리로 보내기** 버튼을 북마크바에 한 번만 끌어놓습니다.
4. 쇼핑몰 주문 화면을 연 상태에서 그 북마크를 누릅니다.
5. 원본 주문과 노란 경고 항목, 결제 총액을 대조한 뒤 엑셀 견적서를 만듭니다.

공개 링크라도 쇼핑몰의 외부 읽기 정책에 따라 직접 분석이 차단될 수 있습니다. 이때 북마크 방식은 로그인된 현재 화면에서 상품 카드만 읽고, 주문 데이터는 URL의 `#` 뒤에 실어 앱으로 넘기므로 서버 요청에 포함되지 않습니다.

링크 방식이 잘 되지 않으면 **문서·사진**에서 쇼핑몰이 내려준 XLSX 또는 PDF를 올립니다. 그다음 권장 수단은 글자를 크게 확대한 장바구니 캡처입니다. 화면 텍스트 붙여넣기는 상품 카드 경계와 가격 의미가 사라질 수 있어 마지막 보조 수단으로만 사용합니다. 주문 텍스트·문서·캡처는 서버에 저장하지 않고 브라우저 안에서 처리합니다.

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

최종 빌드와 검증은 다음 명령으로 실행합니다.

```bash
npm test
```

## 입력 형식

```json
{
  "mall": "coupang",
  "orderNo": "20260821-0001",
  "paidTotal": 77800,
  "items": [
    {
      "내용": "비커 250mL",
      "규격": "붕규산 3.3유리",
      "단위": "개",
      "수량": 20,
      "단가": 2400,
      "금액": 48000,
      "_rawName": "[쿠팡] 무료배송 비커 250mL 20개입",
      "excluded": false
    }
  ]
}
```

## 회계 안전 원칙

- 견적서는 최대 18개의 고정 품목행만 사용합니다.
- 품목이 18개를 넘으면 여러 시트로 나누고 각 시트에 전체 합계와 매수를 표시합니다.
- 각 시트는 `순번 · 내용 · 규격 · 단위 · 수량 · 예상단가 · 예상금액` 순서를 유지합니다.
- 예상금액 셀은 `수량 × 예상단가` 수식으로 생성합니다.
- 결제 총액을 찾지 못하거나 품목 합계와 다르면 차액을 표시하고 견적서 생성을 잠급니다.
- 한 장짜리 견적서에는 불필요한 `1매 중 1매` 문구를 표시하지 않습니다.
- 확실하지 않은 값은 자동 추정하지 않고 규칙 ID와 함께 확인 대상으로 남깁니다.
- 취소·반품 항목은 삭제하지 않고 `excluded: true`로 보존합니다.

이 앱이 만드는 견적서는 학교 내부 품의·정리용 자료입니다. 공급자가 발행한 원본 증빙을 대체하지 않으므로 거래명세서, 세금계산서, 카드전표 등은 별도로 보관하세요.
