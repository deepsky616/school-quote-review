# 견적정리 브라우저 도우미

1. 이 폴더를 내려받아 압축을 풉니다.
2. Chrome 주소창에서 `chrome://extensions`를 엽니다.
3. **개발자 모드**를 켠 뒤 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 폴더를 선택합니다.
5. 쇼핑몰 주문내역 화면에서 확장 프로그램의 **이 페이지의 주문 가져오기**를 누릅니다.

도우미는 현재 탭의 표시된 텍스트에서 품명·수량·금액과 원본 URL만 추출합니다. 쿠키, 비밀번호, 로그인 토큰은 읽거나 저장하지 않습니다. 품목을 2개 이상 찾지 못하면 `[V-P01]`, 행은 찾았지만 값이 비어 있으면 `[V-P02]`로 중단합니다.
